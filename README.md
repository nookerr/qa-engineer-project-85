# Тестирование в продакшене

[![hexlet-check](https://github.com/nookerr/qa-engineer-project-85/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/nookerr/qa-engineer-project-85/actions)

## О проекте

Тестирование в продакшене открытого веб-приложения [Codebattle](https://hexlet.io) — игровой платформы для соревнований по программированию в реальном времени.

В рамках работы над проектом выполнено:
- сбор и классификация требований на основе анализа продукта и документации Wiki (`requirements.yml`);
- проектирование тестовых сценариев для проверки игровой механики, матчмейкинга, реального времени и адаптивности (`test-cases.yml`);
- проведение тестирования в продакшене с использованием Chrome DevTools и фиксацией результатов (`testing-report.yml`);
- оформление баг-репортов в репозитории проекта на GitHub (`issues.yml`);
- регрессионное тестирование ранее закрытых дефектов (`reopened_issues.yml`).
